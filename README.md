# 📊 Sales Analytics Dashboard

Dashboard completo de performance de vendas simulando dados reais de CRM.
Desenvolvido como projeto de portfólio para a área de **Sales Operations**.

---

## 🎯 Objetivo
Analisar o desempenho de uma equipa de vendas através de métricas-chave,
segmentação por região e segmento, e previsão de receita para os próximos meses.

---

## 📈 Métricas analisadas
- **Revenue total:** R$ 13,2M
- **Pipeline value:** R$ 13,2M
- **Win rate:** 33,8%
- **Average deal size:** R$ 78.192
- **Sales cycle length:** 69 dias (média)
- **Performance por vendedor, região e segmento**
- **Previsão de receita (3 meses)**

---

## 🛠️ Ferramentas utilizadas
| Ferramenta | Uso |
|---|---|
| Python + Pandas | Geração e tratamento dos dados |
| SQLite + SQL | Cálculo das métricas |
| Scikit-learn | Modelo de previsão de receita |
| Looker Studio | Dashboard interativo |
| GitHub | Versionamento do código |
